# 📌 Pinboard

Pinboard is a React project I built to practice working with APIs, Redux Toolkit, and reusable React components.

The idea is simple: users can search for visual content, explore the results, and save images they like to their own collection.

## ✨ What I built

- Search for images and visual content
- Fetch results from different image APIs
- Display results in a responsive grid
- Save images to a collection
- View saved images separately
- Switch between Explore and Saved sections
- Show toast messages for user actions
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- React.js
- JavaScript
- Redux Toolkit
- React-Redux
- Axios
- Vite
- CSS

## 🧠 What I Practiced

While building this project, I practiced:

- Creating reusable React components
- Managing global state with Redux Toolkit
- Creating Redux slices
- Using `useSelector` and `useDispatch`
- Working with APIs using Axios
- Handling API responses
- Searching and displaying dynamic data
- Saving and removing items from a collection
- Conditional rendering
- Responsive UI design
